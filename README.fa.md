# نسخهٔ فارسی مهارت اینستاگرام

این فورکِ [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) است که برای محتوای فارسی اصلاح شده. همهٔ ۱۳ مهارت و ۵ ابزار پایتونی نسخهٔ اصلی سر جایشان هستند و رفتارشان روی متن انگلیسی تغییری نکرده. فقط حالا متن فارسی را هم درست می‌فهمند و خرابش نمی‌کنند.

## چه چیزی درست شد

**۱. ابزار انسانی‌سازی دیگر متن فارسی را خراب نمی‌کند.**
نسخهٔ اصلی همهٔ نیم‌فاصله‌ها را پاک می‌کرد و «می‌خوام» را به «میخوام» تبدیل می‌کرد. علامت‌های جهت متن را هم پاک می‌کرد که ترتیب متن ترکیبی فارسی و انگلیسی را به هم می‌زند. حالا نیم‌فاصلهٔ بین دو حرف فارسی و علامت‌های جهت در متن فارسی حفظ می‌شوند. نیم‌فاصله‌های تکراری یا بی‌جا همچنان پاک می‌شوند.

**۲. همهٔ ابزارها فارسی را تشخیص می‌دهند.**
کلمات فارسی بدون شکستن در نیم‌فاصله شمرده می‌شوند. اعداد فارسی (۱۲۳) و عددهای حرفی (سه، صد، میلیون) حساب می‌شوند. اسم ابزارها و برندها با حروف لاتین (مثل ChatGPT) هم نشانهٔ مشخص‌بودن متن حساب می‌شوند، چون فارسی حرف بزرگ ندارد.

**۳. فهرست کلیشه‌های فارسی اضافه شد.**
حدود ۹۰ عبارت کلیشه‌ای فارسی با جایگزین ساده: «می‌باشد»، «در دنیای امروز»، «لازم به ذکر است»، «نقش کلیدی ایفا می‌کند»، «فالو یادت نره» و مانند این‌ها. این عبارت‌ها با نیم‌فاصله، فاصله یا بدون فاصله پیدا می‌شوند. ۱۳ الگوی ساختاری هم علامت‌گذاری می‌شوند، مثل «نه تنها ... بلکه»، «X فقط یک ... نیست»، «آیا می‌دانستید» و «تو این ویدیو».

**۴. بررسی‌های مخصوص کپشن فارسی.**
خطی که با کلمهٔ انگلیسی شروع شود در اینستاگرام چپ‌چین و به‌هم‌ریخته نمایش داده می‌شود. ابزار کپشن حالا این را می‌گیرد. حروف عربی (ي و ك) و نیم‌فاصله داخل هشتگ را هم هشدار می‌دهد. هشتگ‌های فارسی هم حالا شمرده می‌شوند، که در نسخهٔ اصلی اصلاً دیده نمی‌شدند.

**۵. فرمول‌های قلاب فارسی.**
هر ۲۶ فرمول قلاب حالا قالب، مثال و متن روی صفحهٔ فارسی دارند. هر کدام یک الگوی تشخیص فارسی هم دارد تا ابزار تحلیل ریلزهای وایرال بتواند قلاب‌های فارسی را دسته‌بندی کند.

**۶. اعداد به شکل اینستاگرام فارسی.**
در فایل تحلیل وایرال می‌شود تعداد بازدید را همان‌طور که اپ نشان می‌دهد وارد کرد، مثل «۴۱۲ هزار» یا «۱٫۲ میلیون». شکل انگلیسی «412K» هم قبول می‌شود.

## نصب

برای نصب، این دستورها را در ترمینال اجرا کن:

```bash
git clone https://github.com/mehdijamshidian90/instagram-agent-skill.git
cp -r instagram-agent-skill/skills/ig-* ~/.claude/skills/
```

بعد فایل `templates/voice.md` را در `~/.claude/instagram/voice.md` کپی کن و بخش **Language** را پر کن. اگر بنویسی که به فارسی پست می‌گذاری، همهٔ مهارت‌ها قواعد فارسی را رعایت می‌کنند: لحن محاوره، نیم‌فاصله، شروع‌نکردن خط با کلمهٔ انگلیسی، گیومه «» و یک نوع رقم.

## استفاده از ابزارها

```bash
python3 skills/ig-human/humanize.py draft.txt --report   # پاک‌سازی کپشن
python3 skills/ig-human/detect.py draft.txt              # امتیاز انسانی‌بودن
python3 skills/ig-reel/hookscore.py hooks.txt            # رتبه‌بندی قلاب‌ها
python3 skills/ig-reel/beats.py script.txt --target 30   # زمان‌بندی اسکریپت
python3 skills/ig-caption/caption.py caption.txt         # بررسی کپشن
python3 skills/ig-viral/swipe.py captured.tsv            # تحلیل ریلزهای وایرال
```

زبان متن خودکار تشخیص داده می‌شود و تنظیم جداگانه‌ای لازم نیست.

## محدودیت‌ها

آستانه‌های امتیازدهی نسخهٔ اصلی روی قلاب‌های انگلیسی اندازه‌گیری شده‌اند. فهرست کلمات فارسی را من نوشته‌ام و روی مجموعهٔ واقعی از ریلزهای فارسی آزمایش نشده‌اند. پس امتیاز فارسی را مثل نسخهٔ انگلیسی به‌عنوان فیلتر قلاب‌های ضعیف ببین، نه پیش‌بینی بازدید.

سرعت گفتار پیش‌فرض هم از انگلیسی آمده است. یک بار خودت را موقع خواندن یک اسکریپت زمان بگیر و عددش را با گزینهٔ `--wpm` بده.
